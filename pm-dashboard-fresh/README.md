# Project Manager Application

A full-stack project management application built with React and Node.js.

## Features
- Project CRUD operations
- Team management
- Progress tracking
- Feedback system
- Project history

## Quick Start
```bash
npm run install:all
npm run dev
```

> **SQLite developers:** run `npm run check-schema` to ensure your local
> `database/schema.sql` includes any tables added in migrations. Then
> initialise the dev database with `node init-db.js` or `npm run setup-db`.

## Structure
- `/frontend` - React application
- `/backend` - Express.js API
- `/docs` - Documentation
